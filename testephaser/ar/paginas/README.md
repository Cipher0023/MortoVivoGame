# Páginas do livro para a realidade aumentada

Coloque aqui as imagens das páginas que o celular vai reconhecer, uma por arquivo.

- **Formato:** PNG ou JPG.
- **Nome:** o número da fase que a página abre, por exemplo `fase1.png`.
- **Imagem:** a página inteira, como sai na impressão, sem transparência.
- **Tamanho:** de 1000 a 2000 px no lado maior bastam.

Esta pasta guarda as originais. O site não publica estas imagens: o jogo usa
só o arquivo compilado (`targets.mind`), gerado a partir delas.
