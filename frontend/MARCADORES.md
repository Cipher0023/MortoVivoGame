# 🎮 Marcadores para Teste

Para testar o sistema AR do livro MortoVivo, você pode usar QR codes que representam cada página/capítulo.

## 📄 Como Usar os Marcadores

1. Abra este arquivo no navegador ou imprima os QR codes
2. No jogo, clique em "Ativar AR"
3. Aponte a câmera para um dos QR codes abaixo
4. A fase correspondente será carregada!

## 🎯 Botões de Teste

Alternativamente, você pode usar os **botões de teste** que aparecem na tela quando o modo AR está ativado. Eles simulam a detecção de cada capítulo sem precisar de marcadores físicos.

## 🔄 Próximos Passos

Para usar páginas reais do livro sem QR codes:

1. Fotografe cada página do livro
2. Use o MindAR compiler para treinar as imagens
3. Integre os arquivos `.mind` gerados ao sistema
4. As páginas reais serão detectadas automaticamente!
